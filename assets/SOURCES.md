# Asset sources

All images in this folder are self-contained SVG files stored in the repository; nothing is loaded from external services.

- `profile-banner.svg` — original artwork for this profile. The chart shapes are decorative and show no data.
- `skills/*.svg` — skill badges. Logos from [Simple Icons](https://simpleicons.org/) v16.36.0 (CC0 1.0). Brand names and logos are trademarks of their respective owners.
  - `sql.svg`, `excel.svg`, `tableau.svg`, `power-bi.svg` use generic glyphs from [Lucide](https://lucide.dev/) (ISC License), because Simple Icons does not include these brand logos and SQL has no logo. They are not the official product logos.
  - Dark brand colours (DBeaver, CSS, SQLite) are tinted lighter so they stay visible on the dark badge.
- `projects/*.svg` — project cards built from screenshots that are published on the portfolio site (https://digital-universe-6p0.pages.dev/).
